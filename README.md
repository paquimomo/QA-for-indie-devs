# QA for Indie Devs

Plataforma web para analizar la usabilidad de videojuegos indie hechos en Godot.

## Descripción

El sistema permite a desarrolladores subir una build de su juego y recibir
retroalimentación automatizada sobre la experiencia del usuario, simulando
el comportamiento de jugadores reales mediante bots.

## Estructura del proyecto

- `docs/` — Documentación académica del sistema
- `src/` — Código fuente de la aplicación
- `tests/` — Pruebas y documentación TDD

## Documentos disponibles

- Actores del sistema
- Relaciones y casos de uso
- Diagrama de casos de uso
- Modelo de clases UML

## Tecnologías previstas

- Frontend: HTML/CSS/JavaScript (React)
- Backend: Node.js
- Automatización: Playwright y Selenium
- Motor de juego: Godot Engine
